# OneTrace.pro для Magento 2

Подключает магазин на Magento 2 / Adobe Commerce к [OneTrace.pro](https://onetrace.pro) — платформе данных о клиентах (CDP): заказы, покупатели и согласия на рассылку с сервера, трекер сайта, каталог товаров, виджеты рекомендаций и Web Push. Цепочки брошенной корзины, просмотра без покупки, после покупки и возврата клиентов, рекомендации и прогнозы работают сразу после подключения.

[English version](README.md)

- Magento Open Source и Adobe Commerce 2.4.7–2.4.9, PHP 8.2–8.5
- Заказы и их статусы отправляются с сервера через очередь cron с повторами: оформление заказа никогда не ждёт платформу
- Настройки по представлениям магазина: каждое можно подключить к своему проекту; представления одного проекта на других языках переводят его каталог
- Те же события и свойства, что у всех плагинов OneTrace для магазинов, на основе [onetrace-php](https://github.com/OneTracePro/onetrace-php)

## Что передаётся

| Данные | Когда | Как |
|---|---|---|
| `identify` — email, телефон, имя, город, страна, язык | регистрация, вход, изменение аккаунта и адреса, каждый заказ | сервер, секретный ключ |
| Согласие на рассылку | подписка и отписка в магазине: регистрация, личный кабинет, форма в подвале, админка | сервер, вместе с `identify` |
| `order_completed` | заказ оформлен (любое оформление, REST, GraphQL, админка) | сервер |
| `order_paid`, `order_refunded`, `order_cancelled` | счёт оплачен, кредит-нота возвращена, заказ отменён | сервер, один раз на событие заказа |
| `add_to_cart`, `remove_from_cart`, `checkout_started` | изменения корзины и страница оформления — для посетителей с cookie трекера или вошедших | сервер |
| `product_viewed`, просмотры страниц | витрина | трекер в браузере, работает с кэшем страниц и Varnish |
| Каталог товаров | изменения товаров, раз в сутки и кнопка «Выгрузить весь каталог» | сервер, `products.write` |
| `search` | первая страница результатов поиска магазина при включённом «Поиске по товарам» | сервер |

Заказы гостей без cookie трекера связываются по email; последующие события заказа (счёт, возврат) идут от браузера, в котором его оформили, поэтому всё попадает в один профиль.

## Установка

```bash
composer require onetracepro/onetrace-magento2
bin/magento module:enable OneTrace_Connector
bin/magento setup:upgrade
bin/magento setup:di:compile         # в режиме production
bin/magento setup:static-content:deploy
```

1. В проекте OneTrace откройте **Ключи API** и создайте ключ записи (для витрины) и секретный ключ с правом `products.write` (для сервера).
2. В **Магазины → Конфигурация → OneTrace** укажите адрес платформы (домен, по которому вы открываете OneTrace) и оба ключа, нажмите **Проверить подключение**.
3. Убедитесь, что cron Magento работает: очередь отправляется каждую минуту.

## Рекомендации и Web Push

- Виджеты из раздела **Сайт → Виджеты** платформы: укажите их идентификаторы для страницы товара и корзины в настройках или добавьте виджет **Рекомендации OneTrace** в **Контент → Виджеты**. Виджет получает текущий товар, категорию и товары корзины.
- Web Push: включите в настройках — модуль отдаёт `/cdp-sw.js` с корня магазина.

## Языки каталога

Каталог проекта берётся из его первого представления магазина. Остальные представления, подключённые к тому же проекту (тот же адрес и секретный ключ), с другой локалью (**Магазины → Конфигурация → Общие → Настройки локали**) добавляют переводы: названия товаров, ссылки на них в этом представлении, названия категорий и значения видимых характеристик. Платформа показывает рекомендации, виджеты, результаты поиска и письма на языке посетителя.

## Поиск по товарам

Включите **Поиск по товарам** в настройках (поиск должен входить в тариф проекта):

- Страница результатов поиска сохраняет вашу тему и фильтры, но товары, их порядок и количество берутся из OneTrace: словоформы, опечатки, запрос в неверной раскладке, интересы посетителя. Сортировка по цене и фильтры категории и цены передаются платформе.
- В строке поиска при вводе — подсказки трекера: популярные запросы, категории и товары с картинками и ценами.
- Запрос с правилом переадресации («Сайт → Поиск» платформы, например «доставка» → страница доставки) открывает страницу правила вместо результатов. Кэш страниц не хранит переадресации, но популярный запрос, попавший в кэш до появления правила, показывает сохранённые результаты, пока кэш не обновится.
- Фильтры по другим характеристикам, сортировка по названию и любая ошибка платформы оставляют встроенный поиск Magento. Числа в фильтрах считает поиск Magento.

## Конфиденциальность

- При включённом **Режиме ограничения cookie** трекер загружается после разрешения cookie посетителем (отключается в настройках).
- Согласия берутся из штатной подписки магазина на рассылку; «Не активирована» (ждёт подтверждения по email) — ещё не подписка.
- Уже переданные данные остаются в проекте OneTrace; профили удаляются там (GDPR).

## Командная строка

```bash
bin/magento onetrace:test --store=1   # проверка обоих ключей представления магазина
bin/magento onetrace:status           # очередь, последняя ошибка, приостановленные представления
bin/magento onetrace:flush            # отправить ожидающее сейчас
bin/magento onetrace:sync-catalog     # выгрузить весь каталог сейчас
```
